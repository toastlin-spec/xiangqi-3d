# 楚漢棋局

以楚漢相爭為背景的 3D 中國象棋，整個遊戲就是一個 `index.html`，不需要安裝或編譯，用瀏覽器打開就能玩。

## 特色

- **立體 3D 棋盤**：棋子是人物模型，漢軍有韓信、劉邦、張良、蕭何等人，楚軍有項羽、范增、虞姬等人。點一下棋子會顯示這位人物的小傳和這種棋子的走法。
- **平面 2D 模式**：適合較舊的平板或電腦。
- **對局方式**：執漢軍（紅方先行）或執楚軍與電腦對弈，也可以雙人同屏輪流下。
- **電腦棋力**：新兵、校尉、大將軍三種難度。電腦在背景執行緒思考，畫面不會卡住。
- **完整規則**：馬走日與蹩馬腿、象走田與塞象眼、象不過河、炮隔山打子、王不見王、將軍提示、絕殺與困斃判定。
- **動畫與音效**：移動、吃子、投石車發砲等動畫；古箏背景音樂與音效都是用 Web Audio 即時合成，沒有外部音檔。
- **其他**：悔棋、中文棋譜記錄、切換視角、顯示或隱藏棋字。

## 怎麼玩

- 直接用瀏覽器開啟 `index.html`，或開啟 GitHub Pages 網址（如有啟用）。
- 點選己方棋子後，綠點是可以走的位置，紅圈是可以吃的棋子。
- 3D 模式下拖曳可以旋轉視角，雙指或滑鼠滾輪可以縮放。
- 鍵盤：`Ctrl+Z` 或 `Backspace` 悔棋，`Esc` 取消選取。

## 技術

- [Three.js](https://threejs.org/) r128（由 CDN 載入）
- Canvas 2D、Web Audio API、Web Worker
- 字型：Google Fonts 的 Noto Serif TC 與霞鶩文楷 TC

需要連上網路才能載入 Three.js 與字型；離線時 3D 模式無法使用，會自動改用平面棋盤。
